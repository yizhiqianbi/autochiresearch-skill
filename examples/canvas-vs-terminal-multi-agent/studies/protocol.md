# Study Protocol

## Moderator Script

### 1. Introduction

Read:

"Today you will use two interfaces for supervising multiple AI agents on knowledge-work tasks. The underlying agent capabilities are matched. We are interested in how the interface changes your strategy, not whether you personally are good or bad at the tasks."

### 2. Consent and Background

- Confirm consent
- Collect background questionnaire
- Explain that the session uses synthetic tasks and contains no personal work data

### 3. Training

- Show the shared task frame: multiple agents, one user, several subtasks, possible breakdowns
- Give a `4` minute tutorial for the first interface
- Let the participant complete one warm-up action:
  - assign a task
  - inspect an agent output
  - redirect a drifting agent

### 4. Condition A

Tasks in order:

1. planning / delegation
2. monitoring / synthesis
3. recovery / correction

During each task:

- encourage think-aloud but do not coach the participant toward a specific strategy
- log visible interventions and notable hesitation points
- if the participant is stuck for `90` seconds, remind them they may inspect agent state and intervene

### 5. Post-Condition A Questionnaire

- administer condition questionnaire
- ask one short probe:
  - "What did you have to keep in your head while using this interface?"

### 6. Condition B

- repeat tutorial with the second interface
- run the same three task categories with matched content
- administer the same questionnaire

### 7. Final Comparison Interview

Suggested prompts:

- Which interface made the overall plan easiest to reconstruct?
- Which interface made small corrections easiest?
- Did you ever feel that the interface hid important state from you?
- What would your ideal hybrid interface look like?

### 8. Debrief

- clarify that the session studies interface tradeoffs, not model accuracy alone
- thank the participant and explain compensation

## Researcher Logging Notes

- Mark when a participant switches from monitoring to intervention
- Mark when a participant explicitly asks "what is this agent doing?" or equivalent
- Mark when a participant creates an external note, workaround, or verbal plan reconstruction
- Record recovery latency from first visible failure cue to corrective action

## Materials Needed

- prototype mockup or interactive build
- task sheets with counterbalanced order
- questionnaire form
- scoring rubric for task quality
- observer sheet for interventions and breakdowns
