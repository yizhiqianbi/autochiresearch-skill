## After Each Condition

Prompt shown to the participant:
"Answer the following based on the interface you just used."

Likert items (`1 = strongly disagree`, `7 = strongly agree`):

1. I could tell what each agent was doing without excessive effort.
2. I knew where to intervene when something went wrong.
3. I felt in control of the overall workflow.
4. This interface made it easy to remember the current plan.
5. This interface made it easy to recover from an error.
6. Using this interface felt mentally demanding.
7. Using this interface required substantial effort.
8. I would use this interface for real multi-agent work.

Open questions:

1. What part of this interface most helped you supervise the agents?
2. What part made supervision harder than it needed to be?
3. If you took notes or invented a workaround, what was it?
