# CSV Schema

Synthetic dry-run exports follow this schema:

- `participant_id`
- `condition_order`
- `interface_condition`
- `task_type`
- `consent`
- `completed_session`
- `attention_check_pass`
- `work_role`
- `ai_use_frequency`
- `terminal_familiarity`
- `canvas_familiarity`
- `completion_seconds`
- `task_success_pct`
- `intervention_count`
- `recovery_latency_seconds`
- `workload_mental`
- `workload_effort`
- `transparency_score`
- `control_score`
- `plan_recall_score`
- `reuse_score`
- `strategy_note`
- `friction_note`

Each row represents one participant performing one task under one interface condition.
