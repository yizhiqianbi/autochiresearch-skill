# Examples

This directory stores curated demo cases that are intentionally copied into the repository for sharing,
inspection, and Git distribution.

These are not the default location for active AutoCHIResearch runs.

Rules:

- New live projects should still be created outside the repository by `scripts/autochi.py`
- Only copy a project into `examples/` when it is useful as a stable, shareable snapshot
- Keep examples small enough to version comfortably
- Prefer source artifacts, key outputs, screenshots, and compiled PDFs over transient build caches

Current demo case:

- `canvas-vs-terminal-multi-agent/`
  - a full demo package comparing infinite-canvas and terminal interfaces for multi-agent supervision
