## 原因

根据 HCI Study Designer 技能的规则：

> Do not design a study before the novelty gate is complete. If the user hasn't run novelty assessment yet, ask them to do that first rather than proceeding.

您已明确说明"还没有做过新颖性检索"。在新颖性评估（novelty gate）完成之前，直接进入研究设计存在以下风险：

1. **重复研究风险**：该主题已有相关文献（如 flow state 量表在开发者研究中的应用、AI 编程工具的用户体验研究等），若未先检索，可能设计出一个已被充分研究的课题，浪费研究资源。
2. **研究问题定位不准确**：新颖性检索能帮助您识别现有研究的空白点，从而精确定位您的研究贡献。没有这一步，研究问题可能过于宽泛或已有定论。
3. **方法选择可能不当**：现有研究的方法论综述能指导您选择更合适的研究设计，避免方法上的重复或不足。
