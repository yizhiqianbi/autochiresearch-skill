# HCI Analysis Writer

Use this skill when data collection is complete or the stop criteria have been reached.

## Workflow

1. Load the study spec and reuse its predefined inclusion and exclusion rules.
2. Clean the data and produce an auditable record of removals.
3. Build derived variables and summary tables.
4. Choose analysis methods that match the study design:
   - survey: descriptive statistics, reliability, regression or group comparison when justified
   - prototype study: completion rate, time, usability scales, behavioral logs
   - gameplay study: event sequences plus post-play responses
   - mixed methods: quantitative results plus qualitative coding
5. Generate figures and tables from scripts, not by hand.
6. Write results and methods text with `scientific-writing`.
7. Clean and verify references with `citation-management` before final paper assembly.

## Rules

- Do not change exclusion rules after looking at full results without documenting the reason.
- Separate objective results from interpretation.
- Keep figure and table generation reproducible.
- Link every reported claim back to a concrete analysis artifact.

## Outputs

Produce these artifacts whenever possible:

- cleaned data summary
- exclusion log
- results tables
- figures
- manuscript-ready results prose
- limitations notes
